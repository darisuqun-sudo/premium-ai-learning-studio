# Premium AI Learning Studio — نۇسخا 0.2.0

ئۇيغۇرچە ئاساسلىق تىللىق، RTL/LTR قوللايدىغان، Local-first كۆرۈنمە يۈز بىلەن ئارقا باشقۇرۇش بېتى (Admin Dashboard) تولۇق ئۇلانغان AI ئۆگىنىش ۋە Prompt/Skill تەتقىقات مۇھىتى.

## 🚀 يېڭىدىن قوشۇلغان ۋە تۇتاشتۇرۇلغان ئىقتىدارلار

1. **ئارقا باشقۇرۇش بېتى بىلەن كۆرۈنمە يۈزنىڭ ئۇلىنىشى:**
   - يۇقىرى تىزىملىكتە (Topbar) بىر كۇنۇپكا ئارقىلىق **«ئارقا باشقۇرۇشقا ئۆتۈش»** بىلەن **«كۆرۈنمە يۈزگە قايتىش»** ئارىسىدا ئالماشتۇرۇش.
   - ئارقا سۇپىدا ئېلان قىلىنغان ياكى تەھرىرلەنگەن دەرسلىكلەر كۆرۈنمە يۈزدىكى «AI دەرسلىرى» گە دەرھال ئۇلىنىدۇ ۋە كۆرۈنىدۇ.
2. **دەرس باشقۇرۇش ۋە مەشىق تەكشۈرۈش ئېقىمى:**
   - **ئارقا سۇپا:** دەرس قوشۇش، تەھرىرلەش، ئۆچۈرۈش، ئېلان قىلىش/توختىتىش ھالىتىنى باشقۇرۇش.
   - **كۆرۈنمە يۈز:** ئوقۇغۇچى دەرسنى ئوقۇپ، ئەمەلىي مەشىق جاۋابىنى يېزىپ تاپشۇرىدۇ.
   - **باھالاش سەپى:** ئوقۇغۇچى تاپشۇرغان مەشىق ئارقا سۇپىنىڭ باھالاش سەپىگە چۈشىدۇ؛ باشقۇرغۇچى Rubric بويىچە نومۇر قويۇپ پىكىر يازىدۇ؛ كۆرۈنمە يۈزدە نەتىجە دەرھال ئەكس ئېتىدۇ.
3. **قۇرۇلمىلىق سىناق ۋە بوغچا تەكشۈرۈشى:**
   - ZIP ئارخىپىدىكى ھۆججەتلەر ۋە `references/...` ئۇلىنىشلىرى دەلىللىنىدۇ.
4. **تولۇق ساندان زاپاسلاش ۋە ئەسلىگە كەلتۈرۈش:**
   - دەرسلەر، تاپشۇرۇقلار، Prompt لار ۋە Skill خاتىرىلىرىنى بىرلىكتە JSON چۈشۈرۈش ۋە قايتا ئەكىرىش.

## 🛠️ قاچىلاش ۋە ئىجرا قىلىش

Node.js 20+ تەۋسىيە قىلىنىدۇ.

```bash
cd premium-ai-learning-studio
npm install
npm run dev
```

سىناق ۋە Build:

```bash
npm test
npm run build
```

- `npm test`: بارلىق Vitest سىناقلىرى مۇۋەپپەقىيەتلىك ئۆتىدۇ.
- `npm run build`: TypeScript ۋە Vite ئىشلەپچىقىرىش قۇرۇلمىسى (production build) تولۇق ھاسىل بولىدۇ.
