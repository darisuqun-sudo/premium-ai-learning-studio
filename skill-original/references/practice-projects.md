# Stage Projects and Advancement Criteria

بۇ پىلان تەۋسىيە قىلىنغان ئۆگىنىش يولى. پەقەت ئۆگەنگۈچىنىڭ كۆرسەتكەن خىزمىتىنى تاماملاندى دەپ بەلگىلەڭ.

| Stage | نىشان | مەشىق ۋە بىلىم سىنىقى | Prompt design project | ئۆتۈش شەرتى |
|---|---|---|---|---|
| Beginner | Goal, task, context, format نى چۈشىنىش | ئومۇمىي Prompt قا كەم 3 مەزمۇن قوشۇش؛ role/context/task نى تونۇش | كۈندىلىك بىر ئىشنى ئېنىق prompt قا ئايلاندۇرۇش | 10 نومۇرلۇق rubric دا ≥7 ۋە task نى چۈشەندۈرۈش |
| Foundation | Constraints، assumptions، zero/few-shot | زىت ياكى كەم constraint نى بايقاش | 3 مىساللىق classifier prompt لايىھەلەش | format ۋە edge case نى توغرا بەلگىلەش |
| Intermediate | Output validation، iteration، research/code prompting | قەستەن خاتالىق بار چىقىرىشنى تەكشۈرۈش | JSON ياكى code review workflow | سىناق ئۆلچىمى بىلەن نەتىجىنى سېلىشتۇرۇش |
| Advanced | decomposition، multimodal، tool workflow | ئىككى باسقۇچلۇق workflow دا failure point نى تېپىش | multi-step research ياكى code workflow | tool availability، source check، error path نى قاپلاش |
| Professional | prompt system، evaluation set، iteration | A/B نەتىجىسىنى چۈشەندۈرۈش | كۆپ ئىشلىتىلىدىغان prompt system ۋە rubric | repeatable test، version comparison، risk handling |
| Expert Practice | مۇرەككەپ ھەقىقىي تۈرنى باشقۇرۇش | چەك/خەتەر/پەرقلىق مەنبەلەرنى تەھلىل قىلىش | چەكلىمىسى ئېنىق end-to-end AI workflow | observable evidence، failure recovery ۋە maintainability نى كۆرسىتىش |

ئۆتۈش شەرتى دەل بىر رەقەملىك score ئەمەس: rubric، explanation ۋە ئەمەلىي چىقىرىشنى بىرلىكتە باھالاڭ. يېتەرسىزلىك بولسا قوشۇمچە مەشىق بېرىپ قايتا سىناڭ.

## Project checklist

- مەسىلە ۋە ئابونتنىڭ مەقسىتى.
- كىرگۈزۈش، چىقىرىش ۋە data sensitivity.
- بىر ياكى كۆپ باسقۇچ ۋە tool dependency.
- سىناق مىساللىرى: نورمال، چېگرا، كەم ئۇچۇر، قەستەن خاتا مەزمۇن.
- باھالاش rubric، failure handling، human review لازىم بولىدىغان چېگرا.
- قايسى ئۆزگىرىشلەرنى version control قىلىش ۋە قايتا سىناش.

بۇ checklist نى مەشىق تۈرىگە ماسلاشتۇرۇڭ؛ ھەممە قۇرنى ھەر prompt قا زورلاپ قوشماڭ.
