# Prompt Fundamentals and Beginner Lessons

Use this reference for Beginner and Foundation teaching. Teach one lesson at a time; the learner's reply to the exercise is the stopping point.

## Curriculum map

| Stage | Focus | Suggested lessons |
|---|---|---|
| Beginner | What prompts do; goal, audience, context, task, constraints, output | 1. Professional prompt basics; 2. Specify task and audience; 3. Constraints and output format |
| Foundation | Model strengths and limits; examples; iteration and checking | 4. Context and assumptions; 5. Zero-shot and few-shot; 6. Check, critique, revise |

The lesson sequence can be adapted to the learner's goals. Do not mark a lesson complete until the learner completes its exercise or explicitly chooses to skip it.

## Standard lesson structure

Include a title, learning goals, why it matters, concepts, plain explanation, weak prompt, diagnosis, improved prompt, step-by-step improvement, realistic use, learner exercise, rubric, correction guidance, brief recap, and next-lesson preparation. Provide a short exercise, then wait. Use Uyghur explanations and retain English technical vocabulary alongside it.

## Lesson 1: كەسپىي Prompt نىڭ ئاساسى (Professional Prompt Basics)

### ئۆگىنىش نىشانى

دەرس ئاخىرىدا ئۆگەنگۈچى ئېنىق بىر مەقسەتنى، لازىملىق Context نى، كونكرېت Task نى ۋە پايدىلىق Output Format نى بىر Prompt قا يازالايدۇ.

### نېمە ئۈچۈن مۇھىم؟

AI سىزنىڭ كۆڭلىڭىزدىكى ئەمەس، يېزىلغان كۆرسەتمە ۋە تەمىنلەنگەن مەزمۇنغا ئاساسەن جاۋاب بېرىدۇ. ئېنىق تەلەپ قايتا-قايتا سىناشنى ئازايتىپ، نەتىجىنى باھالاشنى ئاسانلاشتۇرىدۇ.

### ئاساسىي ئۇقۇملار

- **Goal (مەقسەت):** جاۋابتىن كېيىن نېمە ئىش قىلماقچى؟
- **Context (مەزمۇن):** AI غا ۋەزىپىنى چۈشىنىشكە كېرەكلىك ئارقا كۆرۈنۈش.
- **Task (ۋەزىپە):** AI قىلىدىغان كونكرېت ھەرىكەت.
- **Constraints (چەكلىمە):** ئۇزۇنلۇق، تىل، ئۇسلۇب، چەكلەنگەن ياكى زۆرۈر نۇقتىلار.
- **Output format (چىقىرىش فورماتى):** جاۋابنىڭ شەكلى، مەسىلەن تىزىملىك ياكى جەدۋەل.

Role ھەر قېتىم لازىم ئەمەس؛ پەقەت مۇئەييەن كۆزقاراش ياكى كەسپىي ئۇسلۇبقا تەسىر قىلغاندا قوشۇڭ.

### ئاددىي چۈشەندۈرۈش ۋە ناچار Prompt

Prompt بولسا بىر ئادەمگە تاپشۇرۇق چۈشەندۈرگەندەك: نېمە لازىم، قايسى ئۇچۇرغا تايىنىدۇ، نەتىجە قانداق بولۇشى كېرەكلىكىنى دېيىش.

**ناچار:** «ماڭا ساياھەت پىلانى تۈز.»

مەقسەتنىڭ تەپسىلاتى، شەھەر، كۈن، خامچوت، قىزىقىش ۋە چىقىرىش شەكلى يوق. AI بۇلارنى پەرەز قىلىشى ياكى قايتا سورىشى مۇمكىن.

### ياخشىلانغان Prompt

«مەن رىيادتا تۇرىمەن، كېلەر جۈمە كۈنى ئائىلەمدىكىلەر بىلەن شەھەر ئىچىدە يېرىم كۈن سەيلە قىلماقچىمىز. بالىلارغا ماس، دالا ۋە يېمەكلىك تاللىشى بار 3 پىلان تەۋسىيە قىل. ھەر بىرىگە ۋاقىت تەرتىپى، مۆلچەردىكى چىقىم دائىرىسى ۋە پىلاننى ئۆزگەرتىش كېرەك بولىدىغان ئېنىقسىزلىقلارنى قىسقىچە يېزىپ، جەدۋەل شەكلىدە كۆرسەت. ئېچىۋېتىلىش ۋاقتىنى بىلمىسەڭ پەرەز قىلماي، دەلىللەش كېرەكلىكىنى بەلگىلە.»

### قەدەممۇقەدەم ياخشىلاش

1. «ساياھەت پىلانى» دېگەن ئومۇمىي مەقسەتنى «يېرىم كۈنلۈك، ئائىلىگە ماس، شەھەر ئىچى سەيلە» دەپ ئېنىقلىدۇق.
2. ۋاقىت ۋە ئورۇننى قوشۇپ، مۇھىم Context نى بەردۇق.
3. تاللاش سانى ۋە ھەر پىلاندىكى تەركىبلەرنى بەلگىلىدۇق.
4. چىقىرىش فورماتىنى جەدۋەل قىلدۇق.
5. ئۆزگىرىشى مۇمكىن بولغان ئۇچۇرنى تەكشۈرۈلمىگەن ھالدا ھەقىقەت دەپ كۆرسەتمەسلىك شەرتىنى قوشتۇق.

### ھەقىقىي ئىشلىتىش

يېڭى شەھەردە بىر كۈنلۈك پىلان تەييارلاشتا، Context قا ۋاقىت، كىملەر بار، خامچوت ۋە يۆتكىلىش شەكلىنى كىرگۈزۈڭ. ئاندىن ۋاقىت/باھا قاتارلىق ئۆزگىرىشچان ئۇچۇرلارنى مەنبەدىن دەلىللەڭ.

### مەشىق

«مېنىڭ CV مگە ياردەم قىل» دېگەن ناچار Prompt نى ئىشلىتىشكە بولىدىغان Prompt قا ئايلاندۇرۇڭ. ئۆزىڭىز تاللىغان ھەقىقىي ياكى تەقلىدىي كەسىپنى، AI قىلىدىغان ئىشنى، كەم دېگەندە ئىككى چەكلىمىنى ۋە چىقىرىش شەكلىنى ئېنىقلاڭ. شەخسىي ئۇچۇرنى قوشماڭ.

### باھالاش ئۆلچىمى (10 نومۇر)

- مەقسەت ۋە Task ئېنىق (0–2)
- كېرەكلىك Context بار (0–2)
- كەم دېگەندە ئىككى پايدىلىق Constraint (0–2)
- Output format بەلگىلەنگەن (0–2)
- شەخسىي/مەخپىي ئۇچۇر قوغدالغان ۋە تەلەپ ئەمەلىي (0–2)

### خاتالىق تۈزىتىش

ئەگەر نەتىجە ئومۇمىي بولۇپ قالسا، كەم قالغان Context نى قوشۇڭ. ئەگەر Prompt تەبىئىي بولمىغان ئۇزۇنلۇقتا بولسا، پەقەت نەتىجىنى ئۆزگەرتىدىغان تەپسىلاتنى ساقلاڭ. ئەگەر شەرتلەر بىر-بىرىگە زىت بولسا، مۇھىملىقىنى ئېنىقلاڭ ياكى قايتا تۈزۈڭ.

### خۇلاسە ۋە كېيىنكى دەرس

ياخشى باشلىنىش: مەقسەت + مۇناسىۋەتلىك Context + كونكرېت Task + زۆرۈر Constraints + Output format. كېيىنكى دەرس «Task ۋە تاماملىنىش ئۆلچىمىنى ئېنىقلاش» بولۇپ، بۇ مەشىق تاماملانغاندىن كېيىن باشلىنىدۇ.
