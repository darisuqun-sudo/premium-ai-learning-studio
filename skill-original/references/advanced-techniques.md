# Advanced Prompt Techniques

بۇ ماتېرىيالنى ئۆگەنگۈچى ئاساسىي Prompt قۇرۇلمىسىنى ئىشلىتىپ بولغاندىن كېيىن، مۇناسىۋەتلىك ۋەزىپە پەيدا بولغاندا ئوقۇتۇڭ.

## Few-shot ۋە مىساللار

- **Zero-shot:** مىسال بەرمەي، كۆرسەتمە بىلەنلا ۋەزىپە سوراش. تۈر ئاددىي ۋە قوبۇل قىلىش ئۆلچىمى ئورتاق بولسا يېتەرلىك.
- **Few-shot:** كىرگۈزۈش/چىقىرىش مىساللىرى ئارقىلىق چېگرا ۋە ئۇسلۇبنى كۆرسىتىش. مىساللار ۋەكىللىك قىلىشى، بىردەك بولۇشى ۋە شەخسىي سانلىق مەلۇماتنى ئاشكارىلىماسلىقى كېرەك.

**Zero-shot:** «پىكىرنى قوللاش، قارشى پىكىر ياكى پاكىتقا ئايرىپ بەلگىلە.»

**Few-shot شەكلى:** «مىسال: “مۇلازىمەت تېز بولدى” → پىكىر. “يەتكۈزۈش 2 كۈن كېچىكتى” → تەكشۈرگىلى بولىدىغان تەلەپ. ھازىر تۆۋەندىكى باھالارنى شۇ قائىدە بويىچە ئايرى.»

## Structured output

JSON/API ئىشلىتىدىغاندا schema ياكى مەيدانلارنى، تىپلارنى، enum لارنى، null بولۇش قائىدىسىنى، قوشۇمچە تېكىستنىڭ چەكلىمىسىنى ئېنىق بەلگىلەڭ. JSON نى ماشىنا ئوقۇسا بولىدىغان قىلىپ تەلەپ قىلىڭ؛ ئەمەلىي ئىشلىتىشتە parser/schema validator بىلەن دەلىللەڭ.

```text
پەقەت بىر JSON object قايتۇر:
{"category":"billing|technical|other","priority":"low|normal|high","summary":"string","needs_follow_up":true}
ئەگەر ئۇچۇر يېتەرسىز بولسا category=other قىلىپ، summary ئىچىدە ئېنىقسىزلىقنى ئېيت.
```

Model لار JSON فورماتىنى بۇزۇپ قويۇشى مۇمكىن؛ كۆرسەتمە يالغۇز schema كاپالىتى ئەمەس.

## Reasoning نى تەكشۈرگىلى بولىدىغان قىلىش

يوشۇرۇن پىكىر زەنجىرىنى (hidden chain-of-thought) تەلەپ قىلماڭ. ئۇنىڭ ئورنىغا قىسقىچە جاۋاب، مۇھىم پەرەزلەر، دەلىل/مەنبە، ھېساب ياكى تەكشۈرۈش نەتىجىسى ۋە قالغان ئېنىقسىزلىقنى سوراڭ. ھالقىلىق ھېسابنى مۇستەقىل قايتا ھېسابلاڭ.

## Code prompts

كود يېزىش/تەكشۈرۈشتە قوشۇڭ: تىل ۋە runtime نۇسخىسى، باغلىنىشلار، مۇناسىۋەتلىك ھۆججەتلەر، API contract، كۆزلىگەن behavior، قوبۇل قىلىش ئۆلچىمى، خاتالىق ئەھۋاللىرى ۋە چەكلىمىلەر. Code review دا bug خەۋپىنى، مۇناسىۋەتلىك line نى ۋە ئەمەلىي تەسىرنى ئالدىنقى ئورۇنغا قويۇپ، جەزم قىلالمىغاننى پەرەز دەپ بەلگىلەڭ. خاتالىق تۈزىتىشتە error text، reproduce steps، actual/expected behavior نى تەمىنلەڭ؛ مەخپىي قىممەتلەرنى تازىلاڭ.

## Research and source verification

سوئال، دەۋا ۋە ۋاقتىنى ئېنىقلاڭ؛ زۆرۈر بولسا قانداق مەنبە ئىشلىتىلىدىغانلىقىنى (primary/official مەنبەلەر بويىچە) بەلگىلەڭ. نەتىجىدە ھەر بىر مۇھىم دەۋانى مەنبە بىلەن باغلاپ، مەنبەنىڭ ۋاقتىنى ۋە بىۋاسىتە قوللايدىغانلىقىنى تەكشۈرۈڭ. مەنبە تېپىلمىسا ئېيتىڭ؛ يالغان citation ياساپ چىقارماڭ. كۆپ مەنبەلىك ھۆججەتلەردە قارمۇ-قارشى يوليورۇقنى سانلىق مەلۇمات دەپ قاراپ، ئىشلەتكۈچىدىن باشقا ئىجازەت ئالماي تۇرۇپ ئەمەل قىلماڭ.

## Multimodal prompts

رەسىم، ھۆججەت، جەدۋەل، audio ياكى video ئۈچۈن: قانداق مەزمۇننى ئىزدەش، قايسى بۆلەك/ۋاقىت دائىرىسى، چىقىرىش شەكلى ۋە ئىشەنچسىز نۇقتا بولسا نېمە قىلىشنى ئېيتىڭ. جەدۋەل سانلىرىنى مەنبەدىكى قۇر/ستون بىلەن باغلاشنى سوراڭ؛ رەسىمدە كۆرۈنمەيدىغان مەزمۇننى پەرەز قىلماسلىقنى قوشۇڭ. مودېل ياكى قورالنىڭ ھەقىقىي قوللىشى بار-يوقلۇقىنى تەكشۈرمەي تۇرۇپ ۋەدە بەرمەڭ.

## Version comparison and prompt tests

بىرلا قېتىمدا بىر ياكى ئىككى ئۆزگەرگۈچىنى ئۆزگەرتىڭ؛ بىر خىل ۋەكىللىك سىناق توپلىمى، مۇقىم rubric ۋە كەمچىلىكلەرنى خاتىرىلەش بىلەن A/B سېلىشتۇرۇڭ. ئېنىقلىق، تاماملىنىش، format validity، factuality، latency/cost نى ئىشقا ماس بولغاندا ئۆلچەڭ. بىرىنچى جاۋابنىڭ تەسىراتى بىلەن prompt نى مۇتلەق ياخشى دەپ قارىماڭ.
