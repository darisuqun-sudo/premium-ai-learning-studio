# Prompt Review and Evaluation

Prompt قا باھا بېرىش دەسلەپكى دىئاگنوز؛ ھەقىقىي ئىقتىدار ۋەكىللىك قىلىدىغان input لاردا سىناق قىلىنىدۇ.

## 100 نومۇرلۇق rubric

| ئۆلچەم | نومۇر |
|---|---:|
| مەقسەت ۋە مۇۋەپپەقىيەت ئۆلچىمىنىڭ ئېنىقلىقى | 15 |
| Context نىڭ يېتەرلىكلىكى ۋە مۇناسىۋەتلىكلىكى | 15 |
| Task نىڭ ئېنىق بەلگىلىنىشى | 15 |
| Constraints نىڭ توغرىلىقى ۋە ئەمەل قىلغىلى بولۇشى | 10 |
| Output format ۋە structure نىڭ ئېنىقلىقى | 10 |
| ئېنىقسىزلىق، factual error، privacy ۋە misuse خەۋپىنى باشقۇرۇش | 15 |
| ئىشقا ماسلىقى ۋە نەتىجىنى دەلىللەش ئىمكانى | 10 |
| ئىخچاملىق ۋە زۆرۈر بولمىغان يوليورۇقنىڭ يوقلۇقى | 10 |
| **جەمئىي** | **100** |

باھا دائىرىسى: 0–39 ئاجىز؛ 40–59 باشلىنىش؛ 60–74 ئوتتۇرا؛ 75–89 ياخشى؛ 90–100 كەسپىي. ھەر ئۆلچەمدە نېمىنىڭ نومۇرنى چۈشۈرگەنلىكىنى بىر جۈملە بىلەن ئىزاھلاڭ. Prompt قىسقا بولسىمۇ، زۆرۈر كونتېكىست ياكى مۇۋەپپەقىيەت ئۆلچىمى كەم بولسا يۇقىرى نومۇر بەرمەڭ.

## تەھلىل تەرتىپى

1. Prompt نىڭ كۆزلىگەن نەتىجىسىنى بىر جۈملىدە قايتا بايان قىلىڭ.
2. كەم ئۇچۇر، زىت شەرت ۋە پەرەزنى بەلگىلەڭ؛ ھەل قىلغىلى بولمايدىغان مەسىلە بولسا سوراڭ، بولمىسا پەرەزنى ئاشكارا قىلىڭ.
3. rubric نىڭ ھەر بىر قۇرىغا نومۇر بېرىپ جەمئىي نومۇرنى ھېسابلاڭ.
4. ئەڭ مۇھىم 1–3 ياخشىلىنىشنى ئىزاھلاڭ.
5. ئىشلىتىشكە تەييار قايتا يېزىلغان Prompt نى بېرىڭ.
6. ئەمەلىي سىناق ئۈچۈن ئۆلچىگىلى بولىدىغان pass/fail قوبۇل قىلىش شەرتىنى تەۋسىيە قىلىڭ.

## ئەمەلىي سىناق

ئادەتتىكى ۋە قىيىن input لارنى ئۆز ئىچىگە ئالغان ۋەكىللىك توپلامنى ئىشلىتىڭ. ھەر Prompt نۇسخىسىنى ئوخشاش input ۋە مۇمكىن بولسا ئوخشاش model/settings بىلەن ئىجرا قىلىڭ. نىشانغا يەتكەنلىك، format، تەكشۈرگىلى بولىدىغان پاكىت، ئەمەل قىلىش ۋە ambiguity نى باھالاپ نەتىجىنى خاتىرىلەڭ. ئاز ساندىكى مىسالغا ئاساسەن ئومۇمىي خۇلاسە چىقارماڭ.

ئەگەر tool ياكى runtime نى ئىجرا قىلالمىسىڭىز، قۇرۇلما باھاسى بىلەن ئەمەلىي ئىجرا نەتىجىسىنى ئايرىڭ؛ سىناق قىلىندى دەپ يالغان ئېيتماڭ.
