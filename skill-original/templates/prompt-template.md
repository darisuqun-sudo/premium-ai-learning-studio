# Prompt Design Worksheet

ھەر بىر بۆلەك لازىم بولغاندا ئىشلىتىلىدۇ؛ مۇناسىۋەتسىز بۆلەكنى ئۆچۈرۈڭ.

```text
مەقسەت:
[نەتىجىنى نېمە ئۈچۈن ئىشلىتىمەن؟]

Context / input:
[AI غا لازىملىق ئارقا كۆرۈنۈش ياكى مەنبە مەزمۇن]

Task:
[AI قىلىدىغان كونكرېت ئىش ۋە scope]

Constraints:
[تىل، audience، ئۇزۇنلۇق، چەك، لازىملىق/چەكلەنگەن مەزمۇن]

Output format:
[مەسىلەن، headings، table ياكى valid JSON schema]

Success criteria:
[قانداق چىقىرىشنى قوبۇل قىلىمەن؟]

Uncertainty:
[ئۇچۇر يېتەرسىز بولسا سورىسۇنمۇ ياكى assumptions نى بەلگىلەپ داۋام قىلسۇنمۇ؟]

Validation:
[پاكىت، schema، code، ھېساب ياكى source نى قانداق تەكشۈرىمەن؟]
```

Role نى پەقەت ئۇسلۇب ياكى مەخسۇس كۆزقاراشقا ئەمەلىي ياردەم قىلغاندا قوشۇڭ.
